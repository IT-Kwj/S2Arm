# S2Arm v0.6.7

这是 0.6.6 的修复版：iPhone / iPad 上大游戏的即时存档重新能用；修复推送续传白白重推、Apple TV 推完核对失败；修复部分游戏在 iPad 上开着即时存档 30–40 秒闪退；设置里关掉即时存档现在真的关；「地址空间不够」少了误报、说法改成人话；导出时总会带上本版 S2Arm.ipa。
*A fix release for 0.6.6: quick saves work again for big games on iPhone / iPad; resumed pushes no longer re-send everything and Apple TV post-push checks pass; it fixes some games closing 30–40 seconds in on iPad with quick saves on; turning quick saves off in Settings now really turns them off; "not enough address space" appears less often by mistake and is explained in plain words; and exports always include this version's S2Arm.ipa.*

## 修复
- **iPhone / iPad 上大游戏的即时存档重新能用**：地址空间较大的设备上，多数大游戏原先整局关着即时存档——即时存档按整份标准布局判地址够不够，一个容器里装了多款游戏时还按其中最大的那款判。现在按这款游戏实际用到的地址判（随版本附带各款实测的地址用量），选好游戏后再放即时存档区，大多数大游戏都能开即时存档。
  *Quick saves work again for big games on iPhone / iPad. On devices with plenty of address space, most big games used to run with quick saves off for the whole session: room was judged against the full standard layout, and a container holding several games was judged by its largest game. S2Arm now judges by what the chosen game actually uses (the release carries measured address use per game) and places the quick save area after the game is chosen, so most big games can use quick saves.*
- **修复部分游戏在 iPad 上开着即时存档 30–40 秒闪退**：即时存档的虚拟池区原先占了 16 GB 地址，部分游戏在 iPad 上因此开局 30–40 秒就闪退。现在只占 2 GB。
  *Fixed some games closing 30–40 seconds in on iPad with quick saves on. The quick save virtual pool area used to take 16 GB of address space, which made some games close 30–40 seconds after starting on iPad. It now takes 2 GB.*
- **设置里关掉即时存档现在真的关**：在设置里关掉即时存档后，游戏启动时原先照样开着。现在会按设置关掉，日志里也写明开关来自哪里。
  *Turning quick saves off in Settings now really turns them off. Games used to start with quick saves on even after you turned them off in Settings. The setting is now respected, and the log says where the switch came from.*
- **「地址空间不够」少了误报、说法改成人话**：只有这款游戏已知需要的地址确实比可用的多时才提示；提示里说清是系统能给 App 的地址范围，和存储空间无关。
  *"Not enough address space" appears less often by mistake and is explained in plain words. It now only appears when the game is known to need more address space than is available, and it explains that this is the address range the system can give the app, unrelated to storage space.*
- **导出时总会带上本版 S2Arm.ipa**：导出到文件夹时都会附上本版 S2Arm.ipa，游戏库也加了「导出 S2Arm.ipa」入口，说明里写清 IPA 的用途，方便 LiveContainer、SideStore、AltStore 等自签用户更新。
  *Exports always include this version's S2Arm.ipa. Exporting to a folder now always adds this version's S2Arm.ipa, the game library has a new "Export S2Arm.ipa" entry, and the instructions explain what the IPA is for — handy for LiveContainer, SideStore, AltStore and other self-signing users.*
- **修复推送续传白白重推、Apple TV 推完核对失败（#1942）**：推资源包时压缩用的线程数原先随可用内存变，同一块前后压出来的长度不一样：续传认不出已推好的块又从头推，Apple TV 推完核对连续三次失败报错。现在固定线程数，续传只推没推完的块、核对一次过；Windows 上「准备资源（测压缩率）」也不再卡在 0% 二十多分钟。
  *Fixed resumed pushes re-sending everything and Apple TV checks failing after a push (#1942). The number of compression threads used to change with free memory, so the same block came out a different length each time: resumed pushes didn't recognise blocks already sent and started over, and Apple TV's post-push check failed three times in a row. The thread count is now fixed, so resumes only send what's left and the check passes; on Windows, "Preparing resources (measuring compression)" no longer sits at 0% for over twenty minutes.*
- **修复部分游戏从第二局起读写大内存区出错**：用到远端内存段的游戏，窗口收窄后原先把尾部地址还给了系统，宿主的缓冲区落进去，第二局起远端段整段用不了。现在收窄时保留尾部，远端段照常可用。
  *Fixed some games failing to use a large memory region from the second session on. For games that use a far memory segment, trimming the window used to hand the tail back to the system; the host's buffers landed there and the far segment was unusable from the second session on. The tail is now kept when trimming, so the far segment works.*
- **「更新所选」遇到电脑上缺 iPhone 资源包的游戏，先出包再推**，不再报缺资源包。
  *"Update selected" now builds the iPhone resource package first for games that don't have one on the computer, instead of reporting it missing.*
- **体感操作更稳**：扣掉手柄自身的陀螺仪零偏（静止时学习），视角不再慢慢漂。
  *Steadier motion controls: the controller's own gyro drift is learned while still and removed, so the view no longer slowly drifts.*
- **手柄选择页换成双 Joy-Con 后，游戏不会再退回掌机模式**。
  *After switching to dual Joy-Con on the controller page, games no longer drop back to handheld mode.*
- **装机时要装的设备没连上，会照实说「没连上」**，并写明当前连着的是哪台。
  *When the device to install to isn't connected, the message now says so and names the device that is connected.*
- **出包更稳**：Windows 上删旧版本删不掉只提示、不再把已经出好的包判失败；出包工具崩溃时带上调用栈；读不出着色器编译器版本时带上原文；直连编译按实时空闲内存定并行数；直连配置不再因构建号全为 0 拒绝整款。
  *More reliable builds: on Windows, failing to delete an old version is only a warning and no longer fails a finished build; build tool crashes include a stack trace; an unreadable shader compiler version includes the raw output; direct compilation sizes its parallelism by live free memory; and direct profiles no longer reject a whole game because its build ID is all zeros.*

## 系统要求
- 与 0.6.6 相同：Mac 需要 Apple 芯片、macOS 15 或更新；Windows 需要 64 位 Windows 10 或 11；iPhone / iPad 需要 iOS / iPadOS 18 或更新。
  *Same as 0.6.6: Mac with Apple silicon on macOS 15 or later; 64-bit Windows 10 or 11; iPhone / iPad on iOS / iPadOS 18 or later.*
