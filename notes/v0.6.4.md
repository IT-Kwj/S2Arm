# S2Arm v0.6.4

这是 0.6.3 的修复版：修复部分游戏开局崩溃，并降低 CPU 占用；游戏页改成只有「更新」和「导出」两件事；修复 iOS 27 的 iPhone 上所有游戏的即时存档都变灰；修复部分游戏在地址空间不够的设备上卡在开头；修复推送到 Apple TV 失败、只装独立 App 时「安装 S2Arm」不生效；独立 App 每款各自一个 App；iPhone 游戏内可以调画面亮度。
*A fix release for 0.6.3: it fixes some games crashing early on and lowers CPU use; the game page now has just Update and Export; it also fixes quick saves being greyed out for every game on iPhones running iOS 27, fixes some games getting stuck at the start on devices with too little address space, fixes pushing to Apple TV and Install S2Arm on phones with only standalone apps, makes each standalone app its own app, and adds an in-game brightness setting on iPhone.*

## 修复
- **修复 Apple ID 登录输完验证码后报 -22410**：11 月 21 日起，用 Apple ID 登录在输完验证码后会报「-22410 This action could not be completed」，这是苹果那边的变化。升级后需要在启动器里重新登录一次 Apple ID、重新输一次验证码，这是正常的，不是又坏了。
  *Fixes Apple ID sign-in failing with "-22410 This action could not be completed" after entering the verification code (an Apple change from Nov 21). After updating, sign in to your Apple ID once more in the launcher and enter a verification code again — this is expected, not a new problem.*
- **修复部分游戏开局崩溃，并降低 CPU 占用**：0.6.0 起改用的一种线程调度方式会让部分游戏在开局后不久必然崩溃，还让 CPU 占用变高。现在回到 0.6.0 之前的调度：这些游戏不再崩溃，同一款游戏在一台测试 iPhone 上的 CPU 占用降了约两成。
  *Fixed some games crashing early on, and lowered CPU use. A thread scheduling method used since 0.6.0 made some games crash shortly after starting and also raised CPU use. Scheduling is back to how it worked before 0.6.0: those games no longer crash, and CPU use for the same game dropped by about a fifth on a test iPhone.*
- **修复 iOS 27 的 iPhone 上所有游戏的即时存档都变灰（#1867）**：0.6.2 起，在 iOS 27 的 iPhone 上，有的设备找不到即时存档要用的那块地址空间，整局就把即时存档关掉，所有游戏的即时存档按钮都是灰的。现在会改用另一块够大的空间，即时存档照常能用。
  *Fixed quick saves being greyed out for every game on iPhones running iOS 27 (#1867). Since 0.6.2, on some iPhones running iOS 27 the space quick saves need could not be found, so quick saves were turned off for the whole session and the button was greyed out for every game. S2Arm now uses another large enough space, and quick saves work again.*
- **修复部分游戏在地址空间不够的设备上卡在开头**：地址空间偏小的设备上，部分游戏一开局就停在开头不动。现在会把游戏开局要的那块内存放进可用范围，能正常往下走。
  *Fixed some games getting stuck at the start on devices with too little address space. On devices with a smaller address space, some games stopped right at the start. S2Arm now places the memory those games reserve at startup inside the usable range, so they continue normally.*
- **「更新这款」只更新原来装过它的设备**：选中的设备没连着时，不会再把游戏换装到当前唯一连着的那台；「更新这款」只推给装过这款的设备，没装过的会说明原因。
  *Update this game only updates devices that already have it. If the selected device is not connected, the game is no longer installed on whichever single device happens to be connected instead, and Update this game only goes to devices that have the game, explaining why when one does not.*
- **HDR 关着时画面亮度回到 0.5.8 的水准**：关掉 HDR 时，画面的白色亮度回到和 0.5.8 一样。
  *With HDR off, picture brightness is back to 0.5.8 levels. When HDR is turned off, the brightness of white in the picture is the same as in 0.5.8 again.*
- **修复只装了独立 App 的手机上「安装 S2Arm」不生效**：手机上只装着独立 App 时，点「安装 S2Arm」不到一秒就报完成、其实没装，推要通用 S2Arm 的游戏会一直提示「先装 S2Arm」。现在会真的装上。
  *Fixed Install S2Arm doing nothing on phones that only have standalone apps. On a phone with only standalone apps, Install S2Arm reported done in under a second without installing anything, and games that need the universal S2Arm kept asking to install S2Arm first. It now actually installs.*
- **修复 S2Arm 在 LiveContainer 里运行时游戏起不来（#502）**：S2Arm 装在 LiveContainer 里时，LiveContainer 存的证书系统解不开，每款游戏都起不来。现在解不开时改用导入进 S2Arm 的证书签；S2Arm 里也没有证书时，会写清该怎么导入。
  *Fixed games not starting when S2Arm runs inside LiveContainer (#502). The certificate stored by LiveContainer could not be opened by the system, so every game failed to start. S2Arm now signs with the certificate imported into S2Arm when that happens, and if there is none it explains how to import one.*
- **修复推送到 Apple TV 时资源传输失败**：推到 Apple TV 时资源传输原先必定失败，中断后还要整份重推。现在能正常推完，中断后接着推；失败时提示写明是 Apple TV 这一步出的问题。
  *Fixed resource transfer failing when pushing to Apple TV. Pushing to Apple TV used to always fail during the resource transfer, and an interrupted push started over from the beginning. It now completes and resumes after an interruption, and failures say they happened at the Apple TV step.*
- **独立 App：每款各自一个 App，不再互相覆盖**：独立 App 改为每款各自一个 App，装多款不再互相覆盖。之前装过的独立 App 暂时别删，存档迁移随后续版本提供。
  *Standalone apps: each game is now its own app, so installing several no longer overwrites one another. Games you installed as standalone apps before keep their saves in the old app: don't delete the old app yet. A way to move saves over will come in a later version.*

## 新功能
- **游戏页只剩「更新」和「导出」两件事**：「更新这款」只在电脑上把这款补到新版，不连手机、不用确认，做完就显示「无需更新」；「导出…」先选怎么签名（Apple ID / 我的证书 / 自签）、出成通用 S2Arm 还是独立 App，再勾要装到哪几台 iPhone / iPad——一台都不勾就导出到文件夹并打开，勾了就逐台装好、每台单独显示结果。原来的「推到 iPhone」「导出自签包」都并进了「导出…」，启动器也不会再自动装到你没选的设备上。
  *The game page now has just two actions: Update and Export. "Update this game" brings the game up to date on your computer only — no phone, no confirmation — and then shows "Up to date". "Export…" lets you choose how to sign (Apple ID / your certificate / self-sign) and whether to build it into S2Arm or as a standalone app, then tick the iPhones / iPads to install to — tick none to export to a folder and open it; tick some and each one is installed with its own result. The old "Push to iPhone" and "Export self-sign package" are now part of "Export…", and the launcher no longer installs to a device you didn't choose.*
- **iPhone：游戏内调画面亮度**：游戏里打开齿轮菜单，用滑块调画面亮度；每款游戏各自记住。
  *iPhone: in-game picture brightness. Open the gear menu in a game and use the slider to adjust brightness; each game remembers its own setting.*

## 系统要求
- 与 0.6.3 相同：Mac 需要 Apple 芯片、macOS 15 或更新；Windows 需要 64 位 Windows 10 或 11；iPhone / iPad 需要 iOS / iPadOS 18 或更新。
  *Same as 0.6.3: Mac with Apple silicon on macOS 15 or later; 64-bit Windows 10 or 11; iPhone / iPad on iOS / iPadOS 18 or later.*
