# S2Arm v0.6.6

这是 0.6.5 的修复版：修复 iPhone 上游戏声音反复断开；「导出…」导出通用 S2Arm 到文件夹时一并放上本版 S2Arm.ipa；修复 Mac 切到后台后帧率补丁被误关；修复 iOS 诊断包里中文日志变成乱码；检测更新不再收起正在填的 Apple ID 登录。
*A fix release for 0.6.5: it fixes game audio repeatedly cutting out on iPhone; "Export…" to a folder for the universal S2Arm now includes this version's S2Arm.ipa; it also fixes frame-rate patches being switched off after the Mac window goes to the background, fixes Chinese logs in iOS diagnostics turning into garbled text, and checking for updates no longer closes an Apple ID sign-in you are filling in.*

## 修复
- **修复 iPhone 上游戏声音反复断开（#1921）**：iPhone 上声音正常按时播放时，S2Arm 有时会误判声音跑在了前面而重启音频，每重启一次就断一下音，严重时几十秒里断十几次。现在先核对音频的实际播放进度，只有真跑在前面时才重启，正常播放不再断音。
  *Fixed game audio repeatedly cutting out on iPhone (#1921). When audio was playing on time, S2Arm sometimes mistook it for running ahead and restarted the audio, and every restart was a short dropout — in bad cases a dozen or more within tens of seconds. S2Arm now checks the actual playback position first and only restarts when audio really is ahead, so normal playback no longer cuts out.*
- **「导出…」导出通用 S2Arm 到文件夹时一并放上 S2Arm.ipa（#502）**：游戏页「导出…」选通用 S2Arm、一台设备都不勾时，文件夹里除了这款的游戏包，还会放上本版 S2Arm.ipa。LiveContainer、SideStore、AltStore 等自签、没连过电脑的玩家，用它签好装上就能用到新版修复。发布页也附了同一份未签名 S2Arm.ipa。
  *"Export…" to a folder for the universal S2Arm now includes S2Arm.ipa (#502). When you choose the universal S2Arm in "Export…" on the game page and tick no devices, the folder now holds this version's S2Arm.ipa alongside the game package. Players who self-sign with LiveContainer, SideStore, AltStore and so on, and have never connected a computer, can sign and install it to get the latest fixes. The same unsigned S2Arm.ipa is also attached to the release page.*
- **修复 Mac 切到后台后帧率补丁被误关（#1857）**：Mac 上游戏窗口切到后台、又没开「切到别的窗口时暂停」时，后台本来就不出画面，原先会被当成帧率补丁卡住画面而把补丁关掉，下次进游戏也关着。现在后台和睡眠的时间不算，补丁不再被误关。
  *Fixed frame-rate patches being switched off after the Mac window goes to the background (#1857). With the game window in the background and "Pause when switching to another window" off, no frames are drawn anyway, but this was taken as the frame-rate patch freezing the picture, so the patch was switched off — and stayed off next time. Time in the background or asleep no longer counts, so the patch is no longer switched off by mistake.*
- **修复 iOS 诊断包里中文日志变成乱码**：日志里只要有一处被截断的汉字，整份中文日志在诊断包里就变成乱码。现在只把那一处坏的字节替换掉，其余照常可读；之前版本发来的乱码诊断也能还原。
  *Fixed Chinese logs in iOS diagnostics turning into garbled text. A single cut-off character anywhere in a log used to turn the whole log into garbled text in the diagnostic package. Now only the broken bytes are replaced and the rest stays readable; garbled diagnostics sent from earlier versions can be restored too.*
- **检测更新不再收起正在填的 Apple ID 登录**：在设置里点「检测更新」后去登录 Apple ID，更新结果回来时会把设置页和登录面板一起收起，填到一半的账号密码就没了。现在不会再收起。
  *Checking for updates no longer closes an Apple ID sign-in you are filling in. If you clicked "Check for Updates" in Settings and then started signing in to your Apple ID, the result coming back closed Settings together with the sign-in panel and lost what you had typed. It no longer does.*
- **Mac 程序坞图标换成游戏封面（#994）**：Mac 上开局后，程序坞里的图标显示这款游戏的封面；更新说明按界面语言显示。
  *The Mac Dock icon now shows the game cover (#994). After a game starts on Mac, its Dock icon shows the game's cover art; update notes now show in the interface language.*
- **Windows 修正**：静默安装时不再弹出空黑窗（#1919）；出包时自带工具被 Windows 拦下、读不到着色器编译器版本时，提示说清是被拦下、没装还是起不来（#1912）。
  *Windows fixes: silent installs no longer pop up an empty black window (#1919); when Windows blocks the bundled tools during a build or the shader compiler version cannot be read, the message now says whether it was blocked, not installed or failed to start (#1912).*
- **iPhone 窄屏上提示条的按钮不再挤在一起**。
  *Buttons on the prompt bar no longer get squeezed on narrow iPhone screens.*

## 系统要求
- 与 0.6.5 相同：Mac 需要 Apple 芯片、macOS 15 或更新；Windows 需要 64 位 Windows 10 或 11；iPhone / iPad 需要 iOS / iPadOS 18 或更新。
  *Same as 0.6.5: Mac with Apple silicon on macOS 15 or later; 64-bit Windows 10 or 11; iPhone / iPad on iOS / iPadOS 18 or later.*
