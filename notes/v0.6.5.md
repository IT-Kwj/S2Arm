# S2Arm v0.6.5

这是 0.6.4 的修复版：独立 App 之前的存档可以搬进新 App；修复 GPU 内存用满时整台机器卡死；修复导入后第一局提示「地址空间不够」；修复部分游戏地形块变黑和多处画面错误；游戏自己中止后，下次启动会问要不要发诊断；修复 LiveContainer 里的游戏被误标「回电脑推到 iPhone」、游戏在别的盘时「清理缓存」报错。
*A fix release for 0.6.4: saves from earlier standalone apps can now be moved into the new app; it fixes the whole device freezing when GPU memory runs out, fixes "not enough address space" on the first run after importing, fixes terrain blocks turning black in some games and several other picture errors, asks to send diagnostics on the next start after a game stops by itself, and fixes games inside LiveContainer being marked "push from computer again" and Clean cache failing for games on another drive.*

## 修复
- **独立 App 之前的存档可以搬进新 App**：0.6.4 起独立 App 每款各自一个 App，之前装过的独立 App 存档留在旧 App 里。现在把手机连上启动器，对这款点「导出…」、勾上这台手机后开始，启动器会把旧 App 里这款的存档（连同存档索引和用户档案）复制进新 App，旧 App 不动；要么全部搬成、要么一点不动。新 App 里已经有这款的存档时不会覆盖，会说清旧进度在哪。进游戏确认进度没问题，再删旧 App。
  *Saves from earlier standalone apps can now be moved into the new app. Since 0.6.4 each game is its own standalone app, and saves from apps you installed before stayed in the old app. Connect the phone to the launcher, click "Export…" for the game, tick this phone and start: the launcher copies the game's saves (including the save index and user profiles) from the old app into the new one and leaves the old app untouched. The move either fully succeeds or changes nothing. If the new app already has saves for the game, they are not overwritten and you are told where the old progress is. Check your progress in the game, then delete the old app.*
- **修复 GPU 内存用满时整台机器卡死（#327）**：GPU 内存用满时，原先会一直卡着直到整台机器没反应。现在会像游戏挂死一样安全停下，并当场释放占着的显存。
  *Fixed the whole device freezing when GPU memory runs out (#327). When GPU memory filled up, things used to hang until the whole device stopped responding. The game now stops safely, as it does when a game hangs, and frees the GPU memory it was holding right away.*
- **修复导入后第一局提示「地址空间不够」（#1903）**：刚导入的游戏第一次进局时，可能提示「地址空间不够」。现在第一局就会先占好需要的地址空间，不再误报。
  *Fixed "not enough address space" on the first run after importing (#1903). The first time a newly imported game started, it could report that there was not enough address space. The space the game needs is now reserved from the first run, so this no longer appears by mistake.*
- **修复部分游戏地形块变黑（#674、#1911）**：部分游戏里被游戏自己改写过的贴图没有被正确记下，地形一块块变黑。现在显示正常。
  *Fixed terrain blocks turning black in some games (#674, #1911). Textures that a game had drawn into itself were not tracked correctly, so terrain turned black in patches. They now display correctly.*
- **修复多处画面错误**：修复部分游戏清屏范围不全（#1330）、顶点数据越界时画面乱飞（#1783）、压缩贴图取错内容（#1787）、贴图写入和共享缓存出错等问题；出包时发现不一致的着色器程序不再装进去，运行时核对不过会改为现场编译（#1836）。
  *Fixed several picture errors: incomplete screen clears in some games (#1330), stray geometry when vertex data went out of range (#1783), compressed textures reading the wrong content (#1787), and errors with texture writes and the shared cache. Shader programs found to be inconsistent at build time are no longer packaged, and if a runtime check fails the shader is compiled on the spot instead (#1836).*
- **修复部分游戏的绘制命令内存估算偏大（#1904）**：部分较早期的游戏在预录绘制时，S2Arm 估算的命令内存和游戏自带驱动的真实数值不同。现在按真实数值算。
  *Fixed draw command memory being overestimated for some games (#1904). For some older games, the command memory S2Arm estimated for pre-recorded draws differed from the real values of the game's own driver. The real values are now used.*
- **HDR 画面改进**：HDR 画面不再经过放大、画面增强和补帧处理而出错；HDR 画面的截图按显示时同一种方式编码；出图管线按画面格式分别准备。
  *HDR picture improvements. HDR pictures no longer go through upscaling, picture enhancement and frame interpolation, which could break them; screenshots of HDR pictures are encoded the same way as on screen; and the output pipeline is prepared separately for each picture format.*
- **修复 LiveContainer 里的游戏被误标「回电脑推到 iPhone」**：S2Arm 装在 LiveContainer 里、LiveContainer 的证书解不开时，游戏库会按导入进 S2Arm 的证书来判断，不再误标。
  *Fixed games inside LiveContainer being marked "push from computer again". When S2Arm runs inside LiveContainer and LiveContainer's certificate cannot be opened, the game library now checks the certificate imported into S2Arm instead and no longer marks games by mistake.*
- **修复游戏在别的盘时「清理缓存」报错**：游戏放在另一块盘上时，「清理缓存」原先会报「操作路径不属于托管目录」。现在能正常清理。
  *Fixed Clean cache failing for games on another drive. When a game was on another drive, Clean cache used to report that the path was not in a managed folder. It now cleans normally.*
- **「导出…」和「更新这款」补到同一个程度**：导出 .s2arm 或独立 App 时，着色器库会和「更新这款」一样一起补到本版。
  *Export and Update this game now bring a game to the same state. Exporting a .s2arm or a standalone app now also brings the shader library up to this version, the same as Update this game.*
- **出包和推送更稳**：内存小的电脑推资源包时不再因内存不够失败；原件找不到时照实说「原件不在原处 / 盘没连上」，不再说文件没下完整；换了包件后旧的中间文件会清掉重建（#1915）；Windows 上出包收尾删临时目录遇到占用不再把整单判失败；一款游戏失败时，别的游戏的输出不再混进它的失败说明（#1880）。
  *More reliable building and pushing. Pushing resource packs no longer fails for lack of memory on computers with little RAM; when the original file cannot be found the message now says it is not where it was or the drive is not connected, instead of saying the download is incomplete; old intermediate files are rebuilt when the package changes (#1915); on Windows, failing to delete a temporary folder at the end no longer fails the whole job; and output from other games no longer mixes into one game's failure message (#1880).*
- **Apple ID 登录和开发者证书**：苹果服务器暂时拒收时，登录会先等一会儿再连（#1864）；可以导入多张开发者证书，每台设备各用一张（#1409）；证书设置读不了时不再挡住安装，改用 Apple ID 签名并在结果页说明。
  *Apple ID sign-in and developer certificates. When Apple's servers temporarily refuse requests, sign-in now waits a moment before trying again (#1864); you can import several developer certificates and use one per device (#1409); and if the certificate settings cannot be read, installing is no longer blocked — it signs with your Apple ID and says so on the result page.*
- **Windows 总控台显示修正**：窗口窄或用英文时内容不再被截掉；没有名字的手机不再显示一长串编号；读不到总览时不再整块消失。
  *Windows console display fixes. Content is no longer cut off in a narrow window or in English; phones without a name no longer show a long ID; and the overview no longer disappears entirely when it cannot be read.*

## 新功能
- **游戏自己中止后，下次启动问要不要发诊断（#351）**：游戏自己中止退出后，下次打开 S2Arm 会问你要不要把这次的诊断发给我们，方便查原因。
  *Asks to send diagnostics after a game stops by itself (#351). If a game stopped by itself, the next time you open S2Arm it asks whether to send us the diagnostics from that session so we can find the cause.*

## 系统要求
- 与 0.6.4 相同：Mac 需要 Apple 芯片、macOS 15 或更新；Windows 需要 64 位 Windows 10 或 11；iPhone / iPad 需要 iOS / iPadOS 18 或更新。
  *Same as 0.6.4: Mac with Apple silicon on macOS 15 or later; 64-bit Windows 10 or 11; iPhone / iPad on iOS / iPadOS 18 or later.*
